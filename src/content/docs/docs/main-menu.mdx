| Button | What it does |
|---|---|
| **NEW PROJECT** | Starts a new project and takes you to [Step 1](/docs/step-1/artwork/): choose your art. |
| **LOAD LATEST** | Opens the project you saved most recently. |
| **SAVED PROJECTS** | Lists every project so you can open, rename, duplicate, export, import or delete one. See [Saving and opening projects](/docs/projects/). |
| **Gear icon** | Quality and display options. See [Settings](/docs/settings/). |
| **About** | Contact and feedback form, plus optional ways to support the app. |
| **YouTube Tutorials** | Opens the app's video guides on YouTube. |

:::note[Version note]
In version 1.6.0 the first and third buttons say **NEW SETUP** and **SAVED SETUPS**. From 1.6.1 "Setups" are called "Projects" everywhere in the app.
:::
