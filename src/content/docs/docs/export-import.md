---
title: Export and import (.ilwj)
description: Move a project between devices as a small file, and what travels with it.
---

A saved project can be exported as a single **`.ilwj`** file and imported on another device, or on the same one.

## Exporting

1. Open **SAVED PROJECTS** and select the project.
2. Tap **EXPORT**.
3. On iPhone and iPad, the share sheet opens: AirDrop it, save it to Files, or send it by Mail or Messages. On Mac, a save dialog opens.

## Importing

Use the **import icon** on the Saved Projects screen and choose a file. Or open the file from outside the app:

- **iPhone/iPad:** tap the file in Files, Mail or AirDrop and choose Light Mapper.
- **Mac:** double-click the file, or right-click and choose *Open With*.

## What's in the file

The file is small (usually about 1 MB) because it holds the *project*, not the videos:

- grid alignment, size, rotation and layer order
- color, background key, speed, audio and shader settings
- masks, shapes (including your custom shapes) and which grids each affects
- Warp Paint

Videos, images and downloads are **not** inside it.

## What happens on import

- You always get a **new** project, and nothing existing is overwritten. If the name is taken, "(imported)" is added.
- **Library videos** you don't have yet download automatically in the background, with progress messages. (Open the artwork picker once while online if the app says the artwork list isn't on your device yet.)
- **Online videos** are looked up and downloaded the same way.
- **Your own media** can't travel. If you have an import with the same name, kind and length it's linked automatically; otherwise the grid shows "no media" and you can pick the art again with **CHANGE ART**.
- **Different screen shape:** the project is re-fitted to your screen so the layout is preserved, with bars where the original screen didn't reach.
- A file that is damaged or from a newer app version is refused with a message, and nothing changes. If you're told to update the app, do that and try again.
