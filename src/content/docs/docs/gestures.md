## Long presses

| Where | Press and hold… | Result |
|---|---|---|
| Corner calibration | a numbered **grid tile** (≈ ⅔ s) | **Duplicates** that grid |
| Mask tool | a **mask** in the list (≈ ¾ s) | Duplicates the mask |
| Mask tool | a **shape** in the list (≈ ¾ s) | Duplicates the shape |
| Mask tool › Shape Library › My Library | a **thumbnail** (≈ ½ s) | Shows a **delete** button for that shape |
| Nudge arrows, Frame arrows | the arrow | Keeps nudging until you let go |
| Transform overlay | a slider, dial or arrow | Panels and pins clear away so you can see |

A press that turns into a scroll or a drag doesn't count as a long press.

## Touch

| Gesture | Result |
|---|---|
| One finger on the picture | Moves the selected grid (calibration) or shape (mask) |
| Two fingers on the picture | Scales and rotates it |
| Drag a corner pin | Reshapes the grid or mask shape |
| Touch a grid (Auto Grid Select on) | Selects the grid under your finger |

## Without a touch screen (Mac)

Use the mouse for everything above. Where a pinch or twist is needed, switch on **Scale Controls** and **Rotation Controls** for sliders and a dial that do the same job.

## Quick reference

| I want to… | Do this |
|---|---|
| See only the projection | **HIDE CONTROLS**, then tap anywhere to bring controls back |
| See the raw art without effects | Calibration › turn off **Display All Effects** |
| Reach a grid hidden behind others | Calibration › turn off **Auto Grid Select**, use the numbered tiles |
| Change several grids at once | Turn on **Modify All Grids** |
| Undo | The arrow at the top of the right panel |
| Start a grid over | **FULL RESET** |
