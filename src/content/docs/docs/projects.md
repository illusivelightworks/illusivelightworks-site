## Saving

Tap **SAVE PROJECT** in Final Display. It saves the whole project: every grid's alignment and settings, masks, and Warp Paint.

- When there are changes you haven't saved, the button is lit and "You have unsaved changes!" shows under it.
- After saving, the button dims and a brief "saved" message appears.
- **SAVE + CONTINUE** in corner calibration also saves.

## Reopening

- **LOAD LATEST** on the Main menu opens the project you saved most recently.
- **SAVED SETUPS** lists every project.

## The Saved Setups screen

Tap a project in the list to select it. The panel on the right shows when it was created and last modified.

| Control | What it does |
|---|---|
| **Name box** | Rename the project. |
| **OPEN** | Opens the project. |
| **DUPLICATE** | Makes a copy to experiment on. |
| **EXPORT** | Saves a small `.ilwj` file you can share or move to another device. See [Export and import](/docs/export-import/). |
| **DELETE** | Deletes the project. |
| **Import icon** (bottom right) | Makes a new project from a `.ilwj` file. |
| **MAIN MENU** | Back to the Main menu. |

:::caution
Deleting a project can't be undone. Duplicate or export it first if you may want it later.
:::
