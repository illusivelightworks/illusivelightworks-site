---
title: Main menu
description: What each button on the Main menu does.
---

| Button | What it does |
|---|---|
| **NEW** | Starts a new project and takes you to choose artwork. |
| **LOAD LATEST** | Opens the project you saved most recently. |
| **SAVED SETUPS** | Shows every saved project so you can open, rename, duplicate, export, import or delete one. See [Saving and saved setups](/docs/projects/). |
| **SETTINGS** | Quality and display options. See [Settings](/docs/settings/). |
| **ABOUT** | Contact and feedback form, plus optional ways to support the app. |
| **YOUTUBE** | Opens the app's video guide on YouTube. |

:::note
Labels on this screen can change between versions. If a button looks different from this list, the Settings and Saved Setups pages in this guide still apply.
:::
