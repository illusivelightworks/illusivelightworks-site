---
title: Color
description: Adjust hue, saturation, brightness and a color overlay for each grid.
---

The Color tool changes how a grid looks without touching the original video.

## Controls

| Control | What it does |
|---|---|
| **Hue** | Rotates every color around the color wheel. |
| **Saturation** | From washed out to vivid. |
| **Brightness** | Darker to brighter. |
| **Overlay color** (preview with **R**, **G**, **B** sliders) | Tints the whole picture with a color. White leaves the picture unchanged. |
| **Reset** (trash can) | Returns the tool to a new grid's starting values: no hue or saturation shift, full brightness, white overlay. One undo step. |

## Which grid?

Use the arrows beside the small grid number at the top of the panel to pick the grid you're editing. The icon shows whether it's a video, image or shader. Or switch on **Modify All Grids** to change them all at once. Reset follows the same rule.

Each grid keeps its own color settings, saved with the project.
