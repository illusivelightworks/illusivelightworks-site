A little vocabulary makes everything else in the app easier to follow.

## Projects (setups)

A **project** (the app also says **setup**) is everything you've built: all your grids, masks, warp paint and settings. You save and reopen projects by name.

## Grids

A **grid** is one layer of projected art. Each grid shows one video, image or shader, and has its own:

- four-corner alignment
- position, size and rotation
- color settings
- background key
- audio level
- playback speed and position

Grids stack on top of each other. You can add as many as you need, reorder them, duplicate them and remove them. Changing one grid never changes another.

:::note
You can swap the art on a grid without losing its alignment, masks or color settings. Use **CHANGE ART**.
:::

## What is per grid, and what is shared

| Feature | Applies to |
|---|---|
| Corner pins, position, size, rotation | One grid at a time |
| Color, Background Key, Audio, Speed | One grid, or all grids with **Modify All Grids** |
| Shader settings | One grid |
| **Warp Paint** | **Shared** by every grid in the project |
| **Masks** | Belong to the project; each mask is switched on for the grids you choose |

## Three kinds of "grid buttons"

You'll see rows of numbered grid buttons in a few places. They do different things:

1. **Corner calibration:** the active grid you are aligning.
2. **Tool panels (Color, Background Key, Audio…):** which grid the tool edits, or *all* grids with **Modify All Grids** on.
3. **Mask tool, "MASK GRID":** which grids the selected mask applies to. This is not the active grid.

## The three stages

```
Choose artwork  →  Corner calibration  →  Final Display
```

You can go back to calibration from Final Display with **GRID SETUP** (see the warning on that page about unsaved changes).
